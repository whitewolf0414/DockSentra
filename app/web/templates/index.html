Built-in Rules

All rules are configurable in config/rules.yaml. Add or modify rules without touching Python code.

CRITICAL

no_root_user

Container runs as root. A non-root USER instruction is required to limit container-escape blast radius.

CRITICAL

hardcoded_secret

Detects passwords, API keys, secrets, or tokens hard-coded in ENV or ARG instructions.

HIGH

unpinned_base_image

Base image uses :latest. Pin to a specific version for reproducible, auditable builds.

MEDIUM

missing_healthcheck

No HEALTHCHECK instruction found. Required for orchestrators to detect and restart unhealthy containers.

LOW

add_instead_of_copy

ADD is used instead of COPY. COPY is safer — ADD has implicit URL fetching and tar extraction behaviours.
